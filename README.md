# stablyai/skills

Shared Claude Code skills for Stably engineering.

## Installing a skill

Copy the skill directory into `~/.claude/skills/`:

```bash
cp -r claude ~/.claude/skills/
```

Then invoke it as `/<skill-name>` in Claude Code.

## Skills

- [`claude`](./claude/SKILL.md) — Run a prompt through `claude -p` (default model: opus).
